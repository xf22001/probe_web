# Probe Tool

## macOS 首次运行与权限说明

由于 macOS 的安全防护机制（Gatekeeper），首次运行从未签名的开发者处下载的命令行可执行文件 `probetool` 时，可能会遇到以下权限阻碍。请按照以下步骤解决：

### 1. 赋予可执行权限
在终端中进入 `probetool` 所在目录，运行以下命令赋予执行权限：
```bash
chmod +x probetool
```

### 2. 解决“无法验证开发者”拦截
如果您双击或运行主程序时提示 **“无法验证开发者，因此无法打开”** 或 **“已放入废纸篓”**，可任选以下一种方法解决：

#### 方法 A：苹果官方右键信任法（无需终端命令行，推荐 🌟）
1. 打开 **Finder（访达）**，找到 `probetool` 文件。
2. 按住 **Control 键** 的同时点击该文件（或点击鼠标右键），在弹出的菜单中选择 **“打开 (Open)”**。
3. 系统会弹出一个确认提示框，点击 **“打开 (Open)”**。
4. 此时程序将成功运行，且系统会永久记住此信任，以后直接双击或通过命令行即可正常启动。

#### 方法 B：终端命令行一键脱壳法
如果您喜欢使用命令行，可直接在终端中运行以下命令清除隔离属性：
```bash
xattr -d com.apple.quarantine probetool
```
运行完毕后，即可无阻碍正常双击或通过 `./probetool` 启动程序。
